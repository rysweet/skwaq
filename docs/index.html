Methodology

Four-Layer Analysis

Layer 1 - Pattern Detection: Regex-based dangerous API detection (strcpy, sprintf, system, atoi, etc.). Fast, high precision, limited recall.

Layer 2 - Dataflow Analysis: Taint tracking from sources (network, stdin, env) to sinks (memory ops, system calls). Catches use-after-free and injection chains.

Layer 3 - Context Validation: Multi-cycle orchestrator that confirms or invalidates findings based on surrounding code context. Reduces false positives.

Layer 4 - LLM Agent Pipeline: Multiple specialist agents reason about code semantically, like a security researcher. Discovery agents find, validation agents debate, synthesizer decides.

Benchmarks

Fixtures: 7 hand-crafted test cases (C, Python, JavaScript) covering 5 CWE families: buffer overflow (CWE-121), command injection (CWE-78), format string (CWE-134), integer overflow (CWE-190), use-after-free (CWE-416).

NIST Juliet: 45,324 test cases across 116 CWEs (adapter implemented, data download pending).

Scoring

Standard information retrieval metrics: Precision = TP/(TP+FP), Recall = TP/(TP+FN), F1 = harmonic mean. CWE-family matching allows CWE-121 findings to match CWE-119 ground truth (same vulnerability family).
